2. แนวคิด Multi-Class และ One-vs-Rest

ก่อนอ่านโค้ด ต้องเข้าใจว่าโมเดลทำงานอย่างไรเบื้องหลัง

Binary กับ Multi-Class

Binary classification มีคำตอบ 2 แบบ เช่น ลาออก/ไม่ลาออก ส่วน Multi-class มีคำตอบมากกว่า 2 แบบ เช่น เดินทางไปทำงาน “แทบไม่เคย / บ่อย / ไม่เดินทางเลย” แต่ Logistic Regression ดั้งเดิมแยกได้แค่ 2 กลุ่ม จึงต้องมีกลยุทธ์ขยายออกไป

One-vs-Rest (OvR) คืออะไร

OvR สร้าง “ตัวจำแนกสองกลุ่ม” หนึ่งตัวต่อหนึ่งคลาส โดยตัวที่ k เรียนรู้ที่จะตอบว่า “ใช่คลาส k หรือ ไม่ใช่ (คือคลาสที่เหลือรวมกัน)” ตอนทำนาย ให้ทุกตัวให้คะแนน แล้วเลือกคลาสที่คะแนนสูงสุด

ลองเล่น: OvR แปลงป้ายกำกับอย่างไร
เลือกตัวจำแนกที่ต้องการ แล้วดูว่าตัวอย่าง 6 คนถูกเปลี่ยนเป็น “ใช่ / ไม่ใช่” อย่างไร
ข้อดี–ข้อจำกัดของ OvR

ข้อดี: เข้าใจง่าย ใช้กับโมเดลสองกลุ่มใดก็ได้ และตีความรายคลาสได้ตรงไปตรงมา
ข้อจำกัด: แต่ละตัวถูกฝึกแยกกัน คลาสเล็กจะเจอปัญหา “ตัวอย่างบวกน้อยมากเทียบกับลบ” (เช่น 150 เทียบกับ 1,320 ในข้อมูลนี้) และความน่าจะเป็นแต่ละตัวไม่รวมกันเป็น 1 โดยธรรมชาติ ต้องถูกปรับสเกลภายหลัง

ขั้นที่ 3 · เตรียมข้อมูล (Preprocessing)

โมเดลคณิตศาสตร์รับได้เฉพาะตัวเลข จึงต้องแปลงข้อมูลให้พร้อม

Python
# 1) ตัดตัวแปรที่ไม่มีประโยชน์ต่อการทำนายออก
df.drop(['EmployeeNumber', 'Over18', 'EmployeeCount', 'StandardHours'], axis=1, inplace=True)

# 2) Encoding ตัวแปรเป้าหมาย
df['BusinessTravel'] = df['BusinessTravel'].map({'Travel_Rarely': 0,
                                                 'Travel_Frequently': 1,
                                                 'Non-Travel': 2})

# 3) One-Hot Encoding สำหรับตัวแปรกลุ่มประเภท (Categorical)
df = pd.get_dummies(df, drop_first=True)
ทำไมต้องทำแต่ละขั้น
แตะหัวข้อเพื่อดูเหตุผล
1) drop 4 คอลัมน์: EmployeeNumber, Over18, EmployeeCount, StandardHours

EmployeeNumber เป็นรหัสประจำตัว ไม่มีความหมายเชิงการทำนาย ส่วน Over18, EmployeeCount, StandardHours มี “ค่าเดียวเหมือนกันทุกแถว” จึงไม่มีความแปรปรวนให้โมเดลเรียนรู้

2) map เป้าหมายเป็น 0, 1, 2

เปลี่ยนข้อความเป็นรหัสตัวเลข สำคัญ: ตัวเลขนี้เป็นเพียง ป้ายชื่อ ไม่ได้หมายความว่า 2 > 1 > 0 เพราะ OvR มองแต่ละคลาสเป็นกลุ่มอิสระ จึงไม่มีปัญหาเรื่องลำดับ

3) get_dummies(drop_first=True)

แปลงตัวแปรประเภทข้อความเป็นคอลัมน์ 0/1 เช่น OverTime → OverTime_Yes การใช้ drop_first=True ตัดหนึ่งหมวดทิ้งเพื่อเลี่ยงปัญหา Multicollinearity (Dummy Variable Trap)

ที่มาของจำนวนตัวแปรต้นคอลัมน์

ขั้นที่ 7 · Confusion Matrix และเมตริกประเมินผล

เครื่องมือหลักในการดูว่าโมเดลผิดพลาดตรงไหน

Python
import seaborn as sns
from sklearn.metrics import confusion_matrix, classification_report

classes = ovr_model.classes_                  # [0, 1, 2]

# 1) Confusion Matrix
cm = confusion_matrix(y_test, y_pred_ovr)

# 2) แตกค่า TP, FP, FN, TN ระดับคลาส
TP = np.diag(cm)
FP = cm.sum(axis=0) - TP
FN = cm.sum(axis=1) - TP
TN = cm.sum() - (FP + FN + TP)

metrics_df = pd.DataFrame({'Class': classes, 'TP': TP, 'FP': FP, 'FN': FN, 'TN': TN})
print(metrics_df.to_string(index=False))

# 3) Classification Report
target_names_str = [str(c) for c in classes]
report = classification_report(y_test, y_pred_ovr,
                               target_names=target_names_str,
                               zero_division=0)   # กัน Warning เมื่อคลาสไม่ถูกทำนายเลย
print(report)

# 4) Heatmap
plt.figure(figsize=(3, 2))
sns.heatmap(cm, annot=True, fmt='d', cmap='Reds', cbar=True,
            xticklabels=classes, yticklabels=classes,

np.argmax(y_prob) โดยไม่ระบุ axis จะคืนค่า ตำแหน่งเดียว ของค่ามากที่สุดในอาร์เรย์ทั้งก้อน (ถูกแผ่เป็นเส้นตรง) ไม่ใช่คลาสที่ชนะรายคน และตัวแปร y_prob_sorted ก็ไม่ได้ถูกใช้ต่อ หากต้องการคลาสที่ชนะรายคนให้ใช้ np.argmax(y_prob, axis=1) และหากต้องการเรียงจากมากไปน้อยให้ใช้ np.argsort(-y_prob, axis=1)

ขั้นที่ 9 · ROC Curve และ AUC

วัดความสามารถในการจัดอันดับ โดยไม่ขึ้นกับการตัดเกณฑ์ที่ 0.5

แนวคิด

  • ROC พล็อต TPR (= Recall) กับ FPR ที่ทุกค่า Threshold
  • AUC คือพื้นที่ใต้เส้น 0.5 = เดาสุ่ม, 1.0 = สมบูรณ์แบบ
  • Multi-class ทำ ROC แบบ OvR: แต่ละคลาสเป็นบวก ที่เหลือเป็นลบ แล้ววาดทีละเส้น
Python
from sklearn.preprocessing import label_binarize

# แปลง y_test เป็น One-Hot (แถว = คน, คอลัมน์ = คลาส)

# คำนวณ ROC และ AUC ทีละคลาส
ovr_fpr, ovr_tpr, thresholds_dict, ovr_roc_auc = {}, {}, {}, {}
for i in range(len(classes)):
    ovr_fpr[i], ovr_tpr[i], thresholds_dict[i] = roc_curve(y_test_bin[:, i], y_prob[:, i])
    ovr_roc_auc[i] = auc(ovr_fpr[i], ovr_tpr[i])

# ชื่อคลาสสำหรับป้ายกำกับ

Macro-Average ROC

Python
# รวมจุด FPR ทั้งหมดของทุกคลาสเป็นแกน x เดียวกัน
all_ovr_fpr = np.unique(np.concatenate([ovr_fpr[i] for i in range(len(classes))]))

# ประมาณค่า TPR ของแต่ละคลาสบนแกนร่วม แล้วเฉลี่ย
mean_ovr_tpr = np.zeros_like(all_ovr_fpr)
for i in range(len(classes)):
    mean_ovr_tpr += np.interp(all_ovr_fpr, ovr_fpr[i], ovr_tpr[i])
mean_ovr_tpr /= len(classes)

ovr_macro_auc = auc(all_ovr_fpr, mean_ovr_tpr)
print(f"Macro-Average AUC = {ovr_macro_auc:.4f}")
